# まなびノート（study-app）

たつやさん専用の、**聞いて学ぶ1回15分**の学習アプリです。
HTML の基礎と、仕事で使う英単語を、スマホで（画面を見られないときは声だけで）学べます。

- 公開URL（GitHub Pages を有効にしたあと）：https://anko20240323-ctrl.github.io/study-app/
- ログインなし・広告なし・APIキーなし。進み具合はスマホの中（localStorage）だけに保存します。

## 1回の流れ

| 順番 | 内容 |
|---|---|
| 1 | 前回の復習（前に間違えた問題・「あやしい」にした単語から3つまで。なければ飛ばす） |
| 2 | 聞く解説（ブラウザの読み上げで、1文ずつ） |
| 3 | 短い問題（4問・選ぶ形） |
| 4 | 打ってみる（打った結果がその場で見える） |
| 5 | 英語（単語 → 意味 → 例文 を声でくり返す） |

**英単語**（20回・160語：日常10回・コード6回・お店4回）の回は、「前回の復習 → 英単語（単語 → 意味 → 例文、思い出す練習、声で練習がオンなら言ってみる練習）→ 短い問題（その回の全部の単語。英語→意味と意味→英語を交互）」の流れです。単語は `lessons/vocab.js` に1語1行で書きます。問題は単語から自動で作ります。

**英語の日常会話**（あいさつ・買い物・食事）の回は、「会話を聞く（英語 → 日本語の意味 → もう一度英語、最後に英語だけで通し）→ 短い問題 → 英語のフレーズ」の流れです。書き方は `lessons/talk-01.js` の先頭にあります。

**英語の語順**の回は、「聞く解説 → 短い問題 → 語順パズル（日本語を聞いて英語の順番で言う／単語をタップして並べる）→ 英語 → まとめ」の流れです。書き方は `lessons/grammar-01.js` の先頭にあります。

ホームの **✍ 書く練習** では、HTMLの各回のコードを何度でも書いて練習できます（各回5問。「まぜて練習」は終えた回から5問）。問題を足すときは `lessons/html-drills.js` に書きます。お手本から作った**部品ボタン**（はじめは記号ごと：`<` `/` `title` `>` …）をタップして組み立てられます。設定で「タグごと」「使わない」に切りかえられます。

設定の **声で練習する（ためし）** をオンにすると、問題に番号を声で答えたり、英語を言ってみて伝わったかを確かめたりできます（`js/listen.js`。声はブラウザの音声認識で文字にします。iPhone では Apple に送られることがあります）。正解すると「ピコーン♪」と鳴ります。

「声で練習する」をオンにしたときと、レッスンを始めるときに、マイクと音声認識の許可を先に済ませます（1問目で許可の確認が出ないように）。

声のファイルがあるときは、ロック画面・車のハンドル・イヤホンのボタンで「止める・続きから」「次へ（次の文・次の問題）」「前へ（いまの文をもう一度）」が使えます。聞くだけモードでは、1回終わったあと「次へ」で、続けて次の回を始められます。

どの場面でも、下の「⏸ 止める／▶ 続きから」で声を止めたり、止めた所から聞き直したりできます。聞く解説では、文（テロップ）をタップすると、その文から聞き直せます。

どの場面でも「？ わからないを聞く」を押すと、いまの場面の説明・問題・打ったコードをまとめた文章がコピーされます。Claude や Gemini に貼って質問できます。

js/editor.js          コードを打つ場所（打ってみる・書く練習で共通）

js/drill.js           ✍ 書く練習の画面

lessons/html-drills.js 書く練習の問題
lessons/vocab.js      英単語のコース（20回・160語）

## 教材を足すとき

1. `lessons/html-01.js` をまねして、新しいファイルを作る
2. `lessons/catalog.js` の `LESSON_FILES` にファイル名を足す
3. `sw.js` の `PRECACHE` にもファイル名を足し、`VERSION` を1つ上げる

画面の仕組み（`js/`）はさわらなくて大丈夫です。

## 手元で動かす

ビルドの道具はいりません。フォルダで `python3 -m http.server` を実行して、`http://localhost:8000` を開きます。

## わかっている弱点

- ブラウザの読み上げは、スマホの画面を消すと止まりやすいです。声のファイル（下の章）を入れて対策しました。iPhone で画面を消しても続くかは、たつやさんが確認中です。

## 声のファイル（画面を消しても止まりにくい声）

ブラウザの読み上げは、スマホの画面を消すと止まりやすいので、Google Cloud Text-to-Speech で前もって音声ファイル（mp3）を作れるようにしてあります。

- アプリは、`audio/manifest.json` に音声ファイルがある文はそれを再生し、ない文は今までどおりブラウザの読み上げを使います
- 声：日本語 `ja-JP-Neural2-B`（女性）、英語 `en-US-Neural2-F`（女性）。会話の2人は声の高さを変えます
- 料金：Neural2 は毎月 100万文字まで無料（それをこえると 100万文字あたり 16ドル）。いまの教材は全部で約2.2万文字です
  - LRC など、同じ請求先で作った文字数も同じ無料分から引かれます
- レッスンを始めると、その回の音声は自動でスマホに保存されます（設定の「📥 すべての音声を保存する」でまとめて保存もできます）

### 作り方（鍵があるパソコンで）

```
pip install google-auth requests        # はじめの1回だけ
node tools/list_texts.mjs               # 教材を変えたときだけ（audio/texts.json を作り直す）
python tools/make_audio.py --dry-run    # 作る文の数と文字数を見るだけ（お金はかからない）
python tools/make_audio.py              # まだない文だけ作る（確認が出るので y）
git add audio tools/tts-usage.json
git commit -m "音声ファイルを作成"
git push
```

- 鍵の場所は、初期値が `C:/Users/user/.gemini/antigravity/scratch/gcp-key.json`。ちがうときは `--key 場所` か、環境変数 `GOOGLE_APPLICATION_CREDENTIALS`
- **鍵のファイルとその中身は、リポジトリに入れない・コミットしない・チャットに貼らない**（`.gitignore` で `*key*.json` などを除外しています）
- 同じ文は二度と作りません。作った文字数は画面に出て、`tools/tts-usage.json` に月ごとに記録されます
- 1回に作る文字数は、初期値で20万文字までに制限しています（`--limit` で変更）
