# まなびノート（study-app）

たつやさん専用の、**聞いて学ぶ1回15分**の学習アプリです。
HTML の基礎と、仕事で使う英単語を、スマホで（画面を見られないときは声だけで）学べます。

- 公開URL（GitHub Pages を有効にしたあと）：https://anko20240323-ctrl.github.io/study-app/
- ログインなし・広告なし・APIキーなし。進み具合はスマホの中（localStorage）だけに保存します。

## 1回の流れ

| 順番 | 内容 |
|---|---|
| 1 | 前回の復習（前に間違えた問題・「あやしい」にした単語から3つまで。なければ飛ばす） |
| 2 | 聞く解説（ブラウザの読み上げで、1文ずつ） |
| 3 | 短い問題（4問・選ぶ形） |
| 4 | 打ってみる（打った結果がその場で見える） |
| 5 | 英語（単語 → 意味 → 例文 を声でくり返す） |

**英語の日常会話**（あいさつ・買い物・食事）の回は、「会話を聞く（英語 → 日本語の意味 → もう一度英語、最後に英語だけで通し）→ 短い問題 → 英語のフレーズ」の流れです。書き方は `lessons/talk-01.js` の先頭にあります。

**英語の語順**の回は、「聞く解説 → 短い問題 → 語順パズル（日本語を聞いて英語の順番で言う／単語をタップして並べる）→ 英語 → まとめ」の流れです。書き方は `lessons/grammar-01.js` の先頭にあります。

設定の **声で練習する（ためし）** をオンにすると、問題に番号を声で答えたり、英語を言ってみて伝わったかを確かめたりできます（`js/listen.js`。声はブラウザの音声認識で文字にします。iPhone では Apple に送られることがあります）。正解すると「ピコーン♪」と鳴ります。

どの場面でも、下の「⏸ 止める／▶ 続きから」で声を止めたり、止めた所から聞き直したりできます。聞く解説では、文（テロップ）をタップすると、その文から聞き直せます。

どの場面でも「？ わからないを聞く」を押すと、いまの場面の説明・問題・打ったコードをまとめた文章がコピーされます。Claude や Gemini に貼って質問できます。

## ファイルの地図

```
index.html            入り口
css/style.css         見た目
js/storage.js         進み具合の保存（スマホの中だけ）
js/ui.js              画面づくりの小さな道具・コピー・画面を消えにくくする
js/speech.js          読み上げ（声の選び方もここ）
js/listen.js          声の聞き取り・発音のチェック・効果音
js/session.js         1回分の進め方（復習→解説→問題→打つ→英語）
js/app.js             画面の切りかえ（ホーム・レッスン・設定）
lessons/catalog.js    教材の一覧
lessons/html-01.js …  教材（1回分ずつ。書き方は html-01.js の先頭に説明あり）
manifest.webmanifest  ホーム画面に置くための情報（PWA）
sw.js                 電波がなくても開けるようにする係（service worker）
```

## 教材を足すとき

1. `lessons/html-01.js` をまねして、新しいファイルを作る
2. `lessons/catalog.js` の `LESSON_FILES` にファイル名を足す
3. `sw.js` の `PRECACHE` にもファイル名を足し、`VERSION` を1つ上げる

画面の仕組み（`js/`）はさわらなくて大丈夫です。

## 手元で動かす

ビルドの道具はいりません。フォルダで `python3 -m http.server` を実行して、`http://localhost:8000` を開きます。

## わかっている弱点

- スマホの画面を消すと、読み上げが止まることが多いです。いまは「画面をつけたまま聞く」前提です（レッスン中は画面が自動で消えにくくしています）。音声ファイルを先に作って再生する方法は、次の版で相談します。
