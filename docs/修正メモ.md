- **リアのメモ（直し方の案）**

### 2. 英単語を学ぶコースを足す（2026-10-30）
- **いま**：英語は場面（会話・語順）に合わせて学んでいるが、単語を知らないので、問題そのものがわからない（笑）
- **たつやさんの案**：日常とコードで必要な単語を学ぶものを追加。単語と、短い文や内容で単語を学ぶ
- **リアのメモ（作り方の案）**
  - 新しいコース「英単語」。「日常の単語」と「コードの単語」の2つに分ける
  - 1回あたり8〜10語。流れ：単語 → 意味 → 短い例文 → 思い出す練習 →（声で練習がオンなら）言ってみる → 短い問題
  - 会話・語順・HTMLの回に出てくる単語を先に学べる順番にする（例：会話の前に like / eat / buy など）
  - 週末に確認したいこと：1回の語数、最初に何回分作るか、優先したいジャンル（お店・買い物・食事・パソコンなど）
  - 教材の文が増えるので、クレアさんに新しい文の分だけ声のファイルを作ってもらう（文字数は作ったあとにお知らせ）

### 3. 書く練習で、入力する言葉もボタンで選べるようにする（2026-10-30）
- **いま**：記号（< > / " = など）はボタンで入れられるが、「たつやのページ」のような中身の文字は、自分で打つ必要がある
- **たつやさんの考え**：コードを一から書ける必要はなく、**書かれている内容を理解できる程度に書ければ十分**（リアもクレアもいるから）
- **たつやさんの案**：今の記号ボタンに加えて、その問題で入力が必要な言葉（例：**たつやのページ**）もボタンで選べるようにして、サクサク練習できるようにする
- **リアのメモ（作り方の案）**
  - 問題ごとに、お手本から「部品ボタン」を自動で作る。例：`<title>` `たつやのページ` `</title>`
  - 部品は**順番をまぜて**並べ、正しい順にタップして組み立てる形にする（何がどこに入るかを考えるので、「読んで理解する力」がつく）
  - 今までどおり、キーボードで打つこともできるようにしておく
  - **決定（2026-10-30）：記号ごとに分ける**
    - 例：`<` `title` `>` `たつやのページ` `<` `/` `title` `>`
    - たつやさんの理由：`/` を別にすると、始まりのタグか閉じるタグかを、はっきり学べる
    - 中身の文字（`たつやのページ` など）は、ひとかたまりの部品にする
  - あとで「タグごと」（`<title>` `</title>`）に切りかえられるようにしておく。たつやさんが初歩的なコードを覚えたら、切りかえのお願いが来る予定
    - 設定に「部品の大きさ：記号ごと／タグごと」のスイッチを作っておけば、そのときはスイッチだけで切りかえられる
